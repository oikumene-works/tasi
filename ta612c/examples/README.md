# Examples and fixtures

This directory is reserved for small, sanitized examples that can be redistributed safely.

Useful future fixtures include:

- device-info response from firmware 3.50
- normal four-channel live response
- open-probe live response
- below-zero temperature response
- single-frame REC response
- multi-frame REC download
- deliberately bad-checksum frame for parser tests

Fixtures should document whether bytes came from a physical capture, vendor example, or synthetic test case.
